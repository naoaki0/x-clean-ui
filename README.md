# x-clean-ui

X の画面を簡略化する、PC ブラウザと iPhone Safari 共通の Userscript です。

PC・スマホとも、ポスト本文と引用本文の横幅・1行の文字数は制限せず、X標準の折り返しを使用します。

画像・動画付きの引用ポストでは、引用本文だけをPCでは最大3行、スマホでは最大4行にします。スマホ向けの4行表示は、画面幅767px以下かつ主な入力がタッチの環境に適用し、PCでウィンドウを狭くしただけでは3行のままです。実際に上限の行数を超える場合のみ「さらに表示」を表示し、その場で全文展開・「折りたたむ」ができます。通常の本文とテキストだけの引用には適用せず、画像・動画のサイズや操作は変更しません。新規投稿・画面幅の変更・フォント読み込みにも追従します。

展開するのは X がページに読み込んだ引用本文です。X 自体が長文の一部しか読み込んでいない場合、未取得の続きまでは取得しません。

引用本文の「さらに表示」「折りたたむ」は、通常は周囲と同系色の薄い文字・基準フォントの85%の大きさで控えめに表示します。文字にカーソルを合わせる、キーボードでフォーカスする、または押しているときだけ、アクセント色と下線で強調します。引用カード全体のホバーでは強調しません。iPhoneでも探してタップできるよう、完全には隠しません。ページ内に X 公式の「さらに表示」があれば、そのアクセント色とフォント設定を基準にします。まだ公式ボタンがない場合は X の標準ブルーと周囲のフォントを基準にします。クリック時は従来どおり、その場で引用本文を展開・折りたたみます。

返信・リポスト・いいね・表示数・ブックマークのボタンは一覧・詳細画面のどちらでも表示し、通常のボタン列と余白を維持します。共有ボタンは開いたポスト本体だけ表示し、一覧や詳細画面の返信ポストでは隠します。一覧では返信・リポスト・いいね・表示・ブックマークの件数だけを隠します。ポストの詳細を開くと、そのポスト本体だけいいね数・ブックマーク数を表示します。本体の返信（コメント）数・リポスト数・表示数と、詳細画面の返信ポストの件数は隠したままです。本文・画像・動画やその再生ボタンには影響しません。

## インストール（初回のみ）

公開先: https://naoaki0.github.io/x-clean-ui/x-clean-ui.user.js

- PC: 上記 URL を Tampermonkey でインストールします。
- iPhone: Safari で上記 URL を開き、Userscripts 拡張のポップアップからインストールします。Userscripts のサイトアクセス権限を許可してください。
- GitHub Pages の初回公開には、リポジトリの Settings → Pages → Build and deployment → Source を **GitHub Actions** に設定する必要があります。

## 更新

`x-clean-ui.user.js` が唯一の編集元です。変更時にヘッダーの `@version` を上げて `master` に push すると、GitHub Actions がテスト後に `.user.js` とヘッダーだけの `.meta.js` を同じ Pages サイトへ公開します。公開ファイルを手作業で編集する必要はありません。

Tampermonkey はバージョンを使って更新を確認します。iOS Userscripts も `@updateURL` と `@downloadURL` に対応していますが、更新処理は完全な自動化が保証されておらず、ポップアップの更新通知から操作が必要な場合があります。手動で各端末にコードをコピーする必要はありません。

ローカルでの確認: `npm ci` → `npm test`。公開ファイルの生成: `npm run build:userscript`（`dist/` に出力）。
